# Stack and deployment shape

videocastle is a TypeScript monolith: a Fastify backend serves a Vite/React SPA, and an in-process worker runs transcoding by shelling out to `ffmpeg`. Metadata lives in embedded SQLite (via Drizzle) and media on the local filesystem. It ships as a single Docker container deployed with Compose, listening on plain HTTP behind the Operator's own TLS-terminating reverse proxy (e.g. nginx-proxy-manager) rather than bundling one. We chose explicit, decoupled, low-magic tooling over a meta-framework such as Next.js (see ADR-0001), and SQLite + local disk over Postgres/S3 to keep a single-Operator deployment dependency-free apart from `ffmpeg`. Splitting the worker into its own container and moving to Postgres/Redis/S3 is the documented scale-up path for multi-user deployments.
