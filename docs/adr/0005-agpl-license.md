# Licensed under AGPL-3.0

videocastle is licensed under AGPL-3.0. As a self-hostable tool, we chose a network-copyleft license so that anyone who modifies it and offers it over a network must publish their changes — keeping forks open and preventing it from being repackaged as closed-source SaaS. The cost, versus a permissive license like MIT, is that proprietary forks are disallowed and permissive reuse is reduced; we accepted that to protect the open, self-hosting ethos of the project.
